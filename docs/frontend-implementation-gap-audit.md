# Portfolio frontend implementation-gap audit

**20 November 2026 · `main` · commit `e02cb58`**

Start with the authoring workflow. **Save Draft** can publish a post, editing a legacy article can discard its table, and blocks that survive saving can still disappear on the public page. These are three independent failure points. A draft-status check alone would miss both content-loss paths.

Other high-priority findings affect commenter privacy, subscriber opt-out, admin access, inbox updates, and homepage availability. The [earlier implementation audit](implementation-gap-audit.md) records previous work on content wiring and architecture. This audit follows what visitors, authors, and administrators can do with that implementation.

## How to use the backlog

Each row names the affected route, the user-visible consequence, the evidence, and a check that can close the finding. Source locations are repository-relative and refer to the commit above. **High** indicates data loss, unintended publication or account actions, personal information exposure, or a blocked core journey. **Medium** indicates a broken task or an accessibility barrier. **Low** indicates a narrower discoverability, presentation, or metadata issue. Within each section, address high-priority items first.

**Browser** means observed in local Edge. **HTTP** means observed in a local route response. **Fixture** means reproduced with synthetic data in the component, converter, or DOM. **Source** means traced through the implementation. Where a row uses two methods, it identifies which part was reproduced. Acceptance checks are for a future fix.

## Publishing and content preservation

**PUB-01 fixed and verified on 20 November 2026.** The new-post editor regression tests cover Save Draft with Published selected and Publish with Draft selected. Using temporary local records, a signed-out request to the draft URL showed Page Not Found and omitted the draft body. Next.js streamed that page with HTTP 200. The public post API returned 404. Both routes returned the article body for a published control. The table below records the original findings.

**PUB-02 fixed and verified on 20 November 2026.** Opening a legacy Markdown post renders its original body in the editor. A title-only save omits the body from the update. In Edge, a local fixture retained its exact Markdown, including a trailing newline. The reopened editor and signed-out public page showed the new title and the same table headers, escaped pipe, bold percentage, and empty cell.

**PUB-03 fixed and verified on 20 November 2026.** Convert Markdown checks the live draft before offering Apply. An unsupported block stops conversion and the dialog identifies it. In Edge, edited paragraph, list, and code blocks retained their content and order after conversion and save. Cancel and Escape preserved unsaved Markdown. Cancelling an unsupported inline image and immediately saving also retained the latest text. These checks used local fixtures.
